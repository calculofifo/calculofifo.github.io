# Monedo

Plataforma de cursos cortos de educación financiera para jóvenes de 14 a 18 años en España.

```bash
npm install
npm run dev      # http://localhost:3000 — sistema de diseño en /design
npm run check    # lint, typecheck, formato y tests unitarios
```

Convenciones del proyecto en [`CLAUDE.md`](./CLAUDE.md). La guía completa de despliegue en Vercel
llegará en la fase 5 (Root Directory: `monedo`).
